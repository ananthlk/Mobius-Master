# product-awareness v1.1.0

**Commit:** `5f9f18c` · **Branch:** `main` · **Since v1.0.0:** 6 commits, 2026-09-07

## Why this is a MINOR

New capability, and one behaviour change that is a correction rather than a break.
`/search` — the only contract chat depends on — keeps its request and response
shape. The admin routes are new and fail closed. The τ_gap change alters which
questions are answered rather than how an answer is shaped, so no caller needs to
change.

## What changed

- **The document registry moved out of code.** `config.DOC_META` was a hardcoded
  dict, so publishing a document meant a Python change and a redeploy — which is
  why the architecture essay and drilldown reference had never been in the corpus.
  It is now a registry, backed by Postgres in cloud and a JSON file offline.
- **Uploads persist.** Uploaded bodies live in the registry row, not on disk: a
  Cloud Run container has no durable filesystem, so an upload written to
  `corpus/uploads/` was gone at the next restart. The admin surface was
  decorative in cloud before this.
- **An admin surface** at `/admin` with `/admin/{status,docs,reingest}`. Auth is
  fail-closed — an unset `PRODUCT_DOCS_ADMIN_KEY` disables the routes outright
  rather than leaving them open. `/search` stays anonymous because chat calls it
  that way.
- **τ_gap recalibrated 0.35 → 0.63** on live Vertex against the 266-chunk corpus.
  At 0.544 (itself never landed in code), 13 of 22 out-of-scope questions were
  wrongly answered — healthcare questions landing on the architecture documents.
  Zero-leak plateau measured at 0.620-0.640.
- **Long-form documents chunk at H3** when a registry entry opts in, so the seven
  architecture layers retrieve individually instead of as one blob.

## New or changed contracts

- `GET /admin`, `GET /admin/status`, `GET|POST /admin/docs`,
  `DELETE /admin/docs/{filename}`, `POST /admin/reingest` — all new, all
  requiring `Authorization: Bearer $PRODUCT_DOCS_ADMIN_KEY`.
- New table `product_docs_registry` in `mobius_rag`.
- New env: `PRODUCT_DOCS_ADMIN_KEY` (Secret Manager `product-docs-admin-key`).
- `PRODUCT_HELP_TAU_GAP` default changed 0.35 → 0.63. **This value belongs to
  the corpus, not the embedder** — pointing it at a smaller corpus makes the
  service abstain on questions it can answer.
- `/search` unchanged.

## Known gaps carried forward

- τ_gap must be re-probed whenever documents are added in bulk
  (`scripts/calibrate_probe.py`); threshold and corpus have to ship together.
- The image ships `corpus/chunks` but not the source manuals, so a full re-ingest
  in cloud embeds the shipped JSONL plus registry-held uploads. Both ingest paths
  now refuse to reset when they would write nothing.
- Top-1 module accuracy measured at 75% on a 36-question probe.
