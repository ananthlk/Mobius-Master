Mobius Architecture: Five-Layer Stack

How the network brain works, layer by layer

1

User Interface

The operator's voice. Ask anything about policies, denials, appeals. Get instant answers with citations.

Chat Conversational Interface Citations
2

Router (Reasoning Engine)

Decides which strategy works best. Facts? RAG? Web? Reasoning? Learns from feedback what strategy wins.

Strategy A: Facts Strategy B: RAG Strategy C: Web Strategy D: Reasoning Bandit Learning
3

Intelligence (RAG + Facts)

Two-tier knowledge. Certified facts first (instant). Rich corpus second (detailed). Never guesses.

Fact Store Embeddings Vector Index ReAct Reasoning
4

Sourcing & Curation

Keeps knowledge alive. Scrapes policies, classifies documents, embeds chunks, culls outdated content.

Sourcing Agent Curation Agent Deep Research Metadata Tags
5

Evaluation & Feedback

Grades every answer. Tells Router what works. Tells Sourcing what's missing. The system learns.

Eval Command Center Accuracy Grading Latency Tracking Coverage Analysis
How a Question Flows Through the Stack
1
Operator asks (Layer 1) "Can FL Medicaid deny for audio-only ADHD telehealth?"
2
Router decides strategy (Layer 2) Strategy: Try Facts first → RAG with reasoning
3
Facts checked (Layer 3a) No exact fact → escalate
4
RAG searches (Layer 3b) Finds: 3 Medicaid policies + 2 telehealth addenda + ADHD guidance
5
ReAct chains them (Layer 3) Policy X + Addendum Y + Addendum Z → "Can deny if violates real-time requirement"
6
Chat answers (Layer 1) User gets answer in 2 seconds with 3 citations + page numbers
7
Eval grades (Layer 5) ✓ Correct. ✓ Good citations. ✓ Fast. → Router learns: RAG+reasoning works for this type
