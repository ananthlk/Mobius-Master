hard_ceiling_s is 300 for every mode, because default_contract_for_mode() sets it to the full infra deadline. That is why scale_ceiling_for_intent() has no effect — its own docstring says so. A deep-intent query cannot buy wall-clock, and a quick turn and an agentic turn share a hard stop.

Rows 3 and 6 gate extend on 120s. The critic's inline path gates on 275s. Between them the governor says consolidate while the critic funds more gathering — 155 seconds, every agentic turn.

4 · Extension budget — the record that replaces 0 / 1 / 3
