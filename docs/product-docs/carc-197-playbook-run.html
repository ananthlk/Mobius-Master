Four of nine survived, and the five refusals are the product. overreach twice — a precondition claiming more than its quote supports. value_not_in_quote — a payer named that the quote never mentions. quote_not_verbatim — a paraphrase presented as a quotation. critic_no_json — the critic itself failing, counted as a refusal rather than waved through.
The playbook that survived is one branch long. retrospective_medical_necessity_review, and it is marked not an appeal — a claim reconsideration, which is the cheaper path. One sourced branch is a smaller playbook than the five I drew by hand, and unlike those it has a document behind it.
The rewording is the whole difference. Asking “how do I dispute a CARC 197” routed to appeals_lookup_rules — a real curated store that returns no citations, so every field was refused at the document-cited gate. Asking what the manuals state routed to rag: four rounds, 14 documents, quotable text. Same machine, same corpus, same day.
What this says about the denial loop. It can be sourced, and today it sources thin. The gap is not the machine — it is that we hold payor manuals which answer partially and no single document that enumerates the grounds. That is an acquisition, and it is now a specific one.
