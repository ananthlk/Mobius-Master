For Florida Medicaid Community Behavioral Health, procedure code H2017 is psychosocial rehabilitation services. What is the unit definition and what limits apply to how much may be billed?

Chat answers

agentic · 2 reasoning rounds · prose, never asked to format

HCPCS code H2017 for psychosocial rehabilitation services in Florida Medicaid Community Behavioral Health is defined in 15-minute increments.

• The billing limit for these services is 1,920 quarter-hour units (480 hours) per state fiscal year.

• H2017 is a Medicaid-only code and is not covered by Medicare.

• Psychosocial rehabilitation aims to help individuals with severe and persistent mental illness develop functional skills for independent living and community participation.

cited: 59G-4.031.pdf, abhfl_medicaid_comprehensive_ltc_provider_manual.pdf, attachment_3-1-A.pdf
