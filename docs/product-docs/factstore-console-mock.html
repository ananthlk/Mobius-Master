What this view is for

Every actor opens to its own output. The Drafter to chat's answer and its full reasoning log. The Assembler to the fields with their quotes. The Judge to per-field verdicts. The Arbiter to what is writable and what is held. No actor is summarised by another.
The log exists because building this screen found it missing. ask_chat_streaming printed each reasoning step to stdout and returned only the answer, so the record of how chat reached a conclusion was discarded every run. It is now persisted with the attempt that produced it — the second time today a display need surfaced a data-loss bug.
The Judge's panel is where a disagreement would be settled. Not "10 of 11 survived", but which one, at which gate, and why. A verdict nobody can inspect is an assertion, and the whole point of this machine is refusing those.
Real output, staged theatrically. The trace, answer, fields, verdicts and rows are from a live run against the corpus. The stage animation is fake — a real run takes minutes and arrives by poll.
