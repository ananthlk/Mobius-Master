The run

Requester — auth module

three inputs, three different kinds — and the difference decides who may see them

Claim — fact. Appeals rulebook — authority, quotable as evidence. Propensity table — a prior. Not evidence, and it does not reach the Judge.

Drafter — ReAct, custom

produces a plan in prose, never asked to format

“Confirm no auth is on file. If the retro-authorization window is open, request retro review. Otherwise file a provider claim dispute within 90 calendar days of the EOP, using the Provider Claim Dispute Request Form, with the clinical record attached.”

Assembler

plan → typed steps, each with action, actor, precondition, deadline, evidence

Five steps. One quote per step — no step borrows another's grounding, exactly as no field borrows another's quote.

Judge — four skills the fact loop does not have

a fact needs support; a step needs support and satisfiability

authority_for_step is it in the rulebook, or invented · precondition_satisfiable do we hold what it needs · deadline_still_open is the clock live · step_ordering does it depend on an earlier outcome

Arbiter

verdicts in, call list out — and this is where propensity finally applies

Supported and satisfiable → executable, ordered. Supported but missing data → dispatch to fetch it first. Unsupported → dropped. Deadline gone → human, no calls.

Three things this case shows that the fact case never did

The propensity table must not reach the Judge. “82% overturn” grounds nothing about whether a step is permitted. A judge that accepts it approves a well-scored step the rulebook does not allow. It belongs to the Arbiter, where it does its real work — ordering the list and deciding whether the effort is worth it. Support first, then rank.
Satisfiability is a gate, not a note. The output is executable. A step that is correct and un-actionable is worse than no step, because it reads as progress while the clock runs. Step 2 is perfectly good advice and cannot be performed — so it becomes a dispatch, not a call.
A dropped step is a sourcing gap, not a mistake. Medicaid fair hearing is a real right in Florida. The Drafter proposed it, the Judge refused it because nothing we hold says so, and the Arbiter dropped it. That refusal is the correct behaviour and a work item: it names a document the rulebook is missing. The same verdict that protects the caller feeds the queue.
The 90-calendar-day deadline, the EOP anchor, the Dispute Request Form and the page numbers are facts this loop sourced and its critic accepted earlier today, from the Sunshine Health provider manual. The claim, the dates and the propensity table are illustrative — the rulebook evidence is not.
