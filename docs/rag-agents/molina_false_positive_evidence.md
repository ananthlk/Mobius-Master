**Source:** molinahealthcare.com/providers/fl/medicaid/home.aspx — public provider homepage, ZERO patient data.
**Result:** gate=phi, **222 flagged spans, 100% false positive.** Real user (Ananth), real extension, real page.

## Two outright detector bugs (not just contact-block over-flagging):
- **`medical_record_number` fires on plain English words** — `Documentation` (@1484), `data` (@9938). These are not identifiers of any kind. Severe MRN-regex over-match.
- **`address` fires on non-address tokens** — `Availity` (@2073, @2527, @5533), `HEDIS` (@9285, @9992), `Sitemap` (@12954). Single business/product words flagged as addresses.

## The classes (all deterministically suppressible per classifier's plan):
- **`name` (majority):** nav menu (`Home Manual Provider Manual and Orientation Forms`), state lists (`Arizona California Florida Idaho…`), section headings (`Prior Authorization Request Procedure`), UI labels (`Rate This Page`, `Very Bad Bad Okay Good`), form questions, footer links. All Title-Case page chrome.
- **`email`:** payer/lab corporate contacts — `mflproviderservicesmanagement@molinahealthcare.com`, `RegionDHEDIS@MolinaHealthCare.Com`.
- **`phone`:** payer/lab numbers — `(855) 322-4076`, `800-845-6167`.
- **`address`/`zip_code`:** payer's own PO Box footer — `P.O. BOX 22812 Long Beach, CA 90801` — plus the token-level false hits above.
- **`date`:** training-session dates (`8/19/26`…) and the copyright/updated date (`last updated: 05/28/2026`).
